# 看视频、听音频、看图（辅助感知）

`perceive` 是辅助感知工具，只补主模型缺的能力：

- **视频 / 音频**：主模型本来就看不了、听不了，用 `perceive`。
- **图片**：主模型自己能看图就直接 `read`，不要用 `perceive`；只有主模型不支持图片时才用它。

## 用法

`perceive({ path: "tmp/xxx.mp4", question: "这段视频讲了什么" })`

`perceive({ path: "https://.../video.mp4", question: "这个人说了什么" })`

`kind` 不传按扩展名判断；认不出来就写 `kind: "image" | "video" | "audio"`。

## 地址必须能直接取到媒体

`path` 只接受两种：

1. 本地文件（`room/`、`表情包/`、`语音/`、`tmp/` 里）；
2. **媒体直链**——打开就是 .mp4 / .mp3 / .jpg 这类文件，或返回媒体内容的 URL。

**B 站/抖音的网页地址、BV 号、分享页不是媒体直链。** 百炼服务端只会拿到 HTML，解析不了。工具也不替你解析这些页面。

遇到网页地址时，你自己想办法拿到真实媒体地址：用浏览器/搜索/站点接口找直链，或者直接问对方要一个能打开的直链。拿到直链后再交给 `perceive`；在线媒体不用下载到本地，服务端会自己拉。

## B 站 / 抖音：直链被防盗链挡住时，下载到本地再看

B 站 CDN 常要 `Referer`，抖音常要 UA/cookie；Omni 在自己机房拉，不会带这些头，所以直链经常 403。这时候别硬塞，走下载：

1. 用浏览器或下载工具把视频下到 `tmp/`，**选低清晰度**（360p / 480p 够看内容），只下你真正要看的那一段；长视频先截取相关片段，别整段下。
2. `perceive({ path: "tmp/xxx.mp4", question: "..." })`。
3. 工具会按 Base64 上限压缩；压不进去会返回「建议直链或分段」，你照实告诉对方，和他商量分段或换更短的片段。
4. **看完就删**：用 `bash` 把 `tmp/` 里下载的原始视频删掉；工具自己产生的压缩临时文件会即时清理，不会留。

B 站、抖音都适用。抖音的访问更依赖 UA/cookie/登录态，失败率更高；拿不到就如实告诉对方，不要假装看到了。

## 本地文件

- 直接给 world 里的相对路径。
- QQ 私聊语音会由桥接转成 mp3 落到 `tmp/qq-*.mp3`，用 `perceive({ path: "tmp/qq-…", kind: "audio" })` 听；如果桥接转不了格式，会明确告诉你听不了。
- Base64 超过上限时工具会先压缩；压不进去会返回「建议直链或分段」，你照实告诉对方，和他商量要不要分段或换直链。
- 机密抽屉里的东西不要送出去。

返回里会写明用的哪个模型；主模型在本地时也会注明「媒体已送到辅助感知模型」。
